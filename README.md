# Sisi

Sisi es una aplicación web progresiva para estudiar vocabulario punjabi de satsangs en Devanagari, con transliteración y traducción al español.

## Contenido

- 3.698 formas de vocabulario
- 693 formas verbales
- 83 partículas
- 56 frases
- 300 combinaciones frecuentes
- 185 lecciones ordenadas por frecuencia
- Repaso espaciado y progreso local

## Publicación en GitHub Pages

Este repositorio no necesita compilación.

1. Abre `Settings > Pages`.
2. En `Source`, selecciona `Deploy from a branch`.
3. Elige la rama `main` y la carpeta `/(root)`.
4. Guarda la configuración.

## Instalación en iPhone

1. Abre la dirección de GitHub Pages en Safari.
2. Pulsa `Compartir`.
3. Selecciona `Añadir a pantalla de inicio`.
4. Activa `Abrir como app web` y pulsa `Añadir`.
5. Abre Sisi una vez con conexión para completar el caché sin conexión.

El progreso se guarda en el dispositivo. Se puede respaldar desde `Ajustes > Exportar progreso`.

## Privacidad

Sisi no utiliza cuentas, publicidad ni analítica. El progreso y los favoritos permanecen en el almacenamiento local del navegador o de la aplicación instalada.
